Desafio 1

Iluminação Inteligente

💡

Presença + Luminosidade → LED

O LED só acende quando há alguém no ambiente e a luz natural está insuficiente, evitando desperdício energético.

🧩 Componentes obrigatórios

Arduino Uno R3 LED (5 mm) Resistor 220 Ω Sensor de presença PIR (HC-SR501) Sensor de luminosidade LDR Resistor 10 kΩ (divisor do LDR) Protoboard e jumpers

📐 Regras de funcionamento

Pessoa presente + ambiente escuroLED ligado (intensidade máxima abaixo de 200 no LDR)
Pessoa presente + ambiente claroLED desligado
Sem pessoaLED desligado, independentemente da luz
Comportamento por intensidadeEntre 200 e 400 no LDR o LED acende em brilho reduzido via PWM

💻 Código do Arduino

// C++ code
// Desafio 1 - Iluminacao Inteligente (PIR + LDR)

const int pirPin = 2;      // Sensor de presenca PIR
const int ldrPin = A0;     // Sensor de luminosidade LDR
const int ledPin = 9;      // LED

void setup()
{
  pinMode(pirPin, INPUT);
  pinMode(ldrPin, INPUT);
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop()
{
  // Le a presenca e a luminosidade
  int presenca = digitalRead(pirPin);
  int luminosidade = analogRead(ldrPin);

  // Comportamento do LED
  mudarLED(presenca, luminosidade);

  Serial.print("Presenca: ");
  Serial.print(presenca);
  Serial.print(" | Luminosidade: ");
  Serial.println(luminosidade);

  delay(150);
}

void mudarLED(int presenca, int luminosidade)
{
  if (presenca == HIGH) {
    if (luminosidade < 200) {
      analogWrite(ledPin, 255);   // ambiente escuro: brilho maximo
    } else if (luminosidade < 400) {
      analogWrite(ledPin, 120);   // penumbra: brilho reduzido (PWM)
    } else {
      analogWrite(ledPin, 0);     // ambiente claro
    }
  } else {
    analogWrite(ledPin, 0);       // sem presenca
  }
}

Desafio 2

Estacionamento Inteligente

🅿️

Ultrassom + Potenciômetro → Alerta visual

O potenciômetro define a distância limite de segurança e o LED avisa o motorista com um piscar cada vez mais rápido conforme o obstáculo se aproxima.

🧩 Componentes obrigatórios

Arduino Uno R3 LED (5 mm) Resistor 220 Ω Sensor ultrassônico HC-SR04 Potenciômetro 10 kΩ Protoboard e jumpers

📐 Regras de funcionamento

Objeto distanteDistância maior que o limite do potenciômetro → LED desligado
Objeto se aproximandoEntre metade do limite e o limite → LED piscando
Objeto na zona críticaAbaixo de metade do limite → LED ligado continuamente
Desafio adicionalO intervalo do piscar cai de 500 ms para 80 ms conforme o objeto se aproxima

Exemplo com limite de 20 cm configurado no potenciômetro: acima de 20 cm o LED fica apagado; entre 10 e 20 cm ele pisca (acelerando); abaixo de 10 cm permanece aceso.

💻 Código do Arduino

// C++ code
// Desafio 2 - Estacionamento Inteligente (HC-SR04 + Potenciometro)

const int trigPin = 12;
const int echoPin = 11;
const int ledPin = 7;      // LED
const int potPin = A0;

unsigned long ultimaTroca = 0;
bool estadoLed = false;

void setup()
{
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop()
{
  // Le o potenciometro e converte numa distancia limite
  int potValue = analogRead(potPin);
  int limiteDistancia = map(potValue, 0, 1023, 2, 200);

  // Dispara o sensor ultrassonico
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  // Calcula a distancia em centimetros
  long duracao = pulseIn(echoPin, HIGH);
  int distancia = duracao * 0.017;

  // Comportamento do LED
  mudarLed(distancia, limiteDistancia);

  // Mostra os valores importantes no monitor serial
  Serial.print("Distancia: ");
  Serial.print(distancia);
  Serial.print("cm | Limite do potenciometro: ");
  Serial.print(limiteDistancia);
  Serial.println("cm");
}

void mudarLed(int distancia, int limite)
{
  if (distancia > limite) {
    // objeto distante: LED desligado
    digitalWrite(ledPin, LOW);
    return;
  }

  if (distancia <= limite / 2) {
    // zona critica: LED ligado continuamente
    digitalWrite(ledPin, HIGH);
    return;
  }

  // objeto se aproximando: pisca cada vez mais rapido (500ms -> 80ms)
  int intervalo = map(distancia, limite / 2, limite, 80, 500);
  if (millis() - ultimaTroca >= (unsigned long)intervalo) {
    estadoLed = !estadoLed;
    digitalWrite(ledPin, estadoLed);
    ultimaTroca = millis();
  }
}

Desafio 3

Ambiente Inteligente (Estufa)

🌱

Temperatura + Umidade → LEDs indicadores

Monitoramento contínuo da estufa com sinalização visual das condições e comunicação de dados pelo Monitor Serial.

🧩 Componentes obrigatórios

Arduino Uno R3 LED verde LED vermelho LED amarelo 3 × Resistor 220 Ω Sensor de temperatura e umidade DHT22 Protoboard e jumpers

📐 Regras de funcionamento

Condição adequadaT ≤ 30 °C e U ≥ 50 % → LED verde ligado
Temperatura elevadaT > 30 °C → LED vermelho ligado
Umidade inadequadaU < 50 % → LED amarelo ligado
Desafio adicionalT alta + U baixa → vermelho e amarelo piscam juntos, sinalizando alerta duplo

Valores de referência definidos para a cultura simulada: temperatura máxima de 30 °C e umidade relativa mínima de 50 %. A representação do alerta duplo usa piscar sincronizado, diferenciando-o das condições isoladas (LEDs fixos).

💻 Código do Arduino

// C++ code
// Desafio 3 - Ambiente Inteligente / Estufa (DHT22)
// Requer a biblioteca "DHT sensor library" (Adafruit) instalada na IDE

#include <DHT.h>

#define DHTPIN 2
#define DHTTYPE DHT22
DHT dht(DHTPIN, DHTTYPE);

const int ledVerde = 5;
const int ledVermelho = 6;
const int ledAmarelo = 7;

const float TEMP_MAX = 30.0;   // limite de temperatura (C)
const float UMID_MIN = 50.0;   // limite de umidade relativa (%)

unsigned long ultimoPiscar = 0;
bool piscaOn = false;
const int intervaloPiscar = 300; // ms, para o alerta duplo

void setup()
{
  Serial.begin(9600);
  dht.begin();
  pinMode(ledVerde, OUTPUT);
  pinMode(ledVermelho, OUTPUT);
  pinMode(ledAmarelo, OUTPUT);
}

void loop()
{
  float temperatura = dht.readTemperature();
  float umidade = dht.readHumidity();

  // Trata falha de leitura do sensor
  if (isnan(temperatura) || isnan(umidade)) {
    Serial.println("Falha na leitura do DHT22");
    digitalWrite(ledVerde, LOW);
    digitalWrite(ledVermelho, LOW);
    digitalWrite(ledAmarelo, LOW);
    delay(1000);
    return;
  }

  bool tempAlta = temperatura > TEMP_MAX;
  bool umidBaixa = umidade < UMID_MIN;

  if (tempAlta && umidBaixa) {
    // Alerta duplo: vermelho e amarelo piscam juntos
    digitalWrite(ledVerde, LOW);
    if (millis() - ultimoPiscar >= intervaloPiscar) {
      piscaOn = !piscaOn;
      digitalWrite(ledVermelho, piscaOn);
      digitalWrite(ledAmarelo, piscaOn);
      ultimoPiscar = millis();
    }
    Serial.println("ALERTA DUPLO");
  }
  else if (tempAlta) {
    digitalWrite(ledVerde, LOW);
    digitalWrite(ledVermelho, HIGH);
    digitalWrite(ledAmarelo, LOW);
    Serial.println("TEMPERATURA ALTA");
  }
  else if (umidBaixa) {
    digitalWrite(ledVerde, LOW);
    digitalWrite(ledVermelho, LOW);
    digitalWrite(ledAmarelo, HIGH);
    Serial.println("UMIDADE BAIXA");
  }
  else {
    digitalWrite(ledVerde, HIGH);
    digitalWrite(ledVermelho, LOW);
    digitalWrite(ledAmarelo, LOW);
    Serial.println("CONDICAO ADEQUADA");
  }

  Serial.print("Temperatura: ");
  Serial.print(temperatura);
  Serial.print(" C | Umidade: ");
  Serial.print(umidade);
  Serial.println(" %");

  delay(1000);
}

Considerações finais

Integração, rastreabilidade e validação

Os três protótipos compartilham a mesma arquitetura de sensoriamento e controle: leitura periódica das entradas, aplicação de regras de decisão baseadas em limites configuráveis e acionamento das saídas. O registro das leituras e do estado do sistema no Monitor Serial garante a rastreabilidade exigida no ambiente industrial, permitindo comparar o comportamento esperado com o observado a cada teste — exatamente o que os quadros de teste acima documentam.
