Desafio 1

Iluminação Inteligente

💡

Presença + Luminosidade → LED

O LED só acende quando há alguém no ambiente e a luz natural está insuficiente, evitando desperdício energético.

🧩 Componentes obrigatórios

Arduino Uno R3 LED (5 mm) Resistor 220 Ω Sensor de presença PIR (HC-SR501) Sensor de luminosidade LDR Resistor 10 kΩ (divisor do LDR) Protoboard e jumpers

📐 Regras de funcionamento

Pessoa presente + ambiente escuroLED ligado (intensidade máxima abaixo de 200 no LDR)
Pessoa presente + ambiente claroLED desligado
Sem pessoaLED desligado, independentemente da luz
Comportamento por intensidadeEntre 200 e 400 no LDR o LED acende em brilho reduzido via PWM

🔌 Circuito montado no Tinkercad

LDR → A0 — divisor resistivo com 10 kΩ para GND; leitura analógica 0–1023.
PIR OUT → D2 — saída digital HIGH quando detecta movimento; VCC em 5 V.
LED → ~D9 — pino PWM em série com resistor de 220 Ω até o GND.
GND comum — todos os componentes compartilham o mesmo terra do Arduino.
🔗 Abrir circuito no Tinkercad

💻 Código do Arduino

/* =========================================================
   DESAFIO 1 - ILUMINACAO INTELIGENTE
   Sensor PIR (presenca) + LDR (luminosidade) -> LED
   Logica:
     Pessoa presente + ambiente escuro -> LED ligado
     Pessoa presente + ambiente claro  -> LED desligado
     Sem pessoa                        -> LED desligado
   ========================================================= */

const int PINO_PIR = 2;    // saida digital do sensor de presenca
const int PINO_LDR = A0;   // divisor resistivo do LDR
const int PINO_LED = 9;    // pino PWM para controlar o brilho

const int LIMIAR_ESCURO   = 400;  // abaixo disso o ambiente e considerado escuro
const int LIMIAR_MUITO_ESCURO = 200; // abaixo disso usa brilho maximo

void setup() {
  pinMode(PINO_PIR, INPUT);
  pinMode(PINO_LED, OUTPUT);
  Serial.begin(9600);
  Serial.println("Sistema de Iluminacao Inteligente iniciado");
}

void loop() {
  bool presenca = digitalRead(PINO_PIR) == HIGH;
  int  luz      = analogRead(PINO_LDR);   // 0 (escuro) .. 1023 (claro)
  int  brilho   = 0;

  if (presenca && luz < LIMIAR_ESCURO) {
    // Quanto mais escuro, maior o brilho do LED
    brilho = (luz < LIMIAR_MUITO_ESCURO) ? 255 : 120;
  } else {
    brilho = 0;   // sem pessoa OU ambiente ja iluminado
  }

  analogWrite(PINO_LED, brilho);

  // Rastreabilidade do comportamento no Monitor Serial
  Serial.print("PIR=");    Serial.print(presenca ? "HIGH" : "LOW");
  Serial.print("  LDR=");  Serial.print(luz);
  Serial.print("  LED=");  Serial.println(brilho);

  delay(300);
}

Desafio 2

Estacionamento Inteligente

🅿️

Ultrassom + Potenciômetro → Alerta visual

O potenciômetro define a distância limite de segurança e o LED avisa o motorista com um piscar cada vez mais rápido conforme o obstáculo se aproxima.

🧩 Componentes obrigatórios

Arduino Uno R3 LED (5 mm) Resistor 220 Ω Sensor ultrassônico HC-SR04 Potenciômetro 10 kΩ Protoboard e jumpers

📐 Regras de funcionamento

Objeto distanteDistância maior que o limite do potenciômetro → LED desligado
Objeto se aproximandoEntre metade do limite e o limite → LED piscando
Objeto na zona críticaAbaixo de metade do limite → LED ligado continuamente
Desafio adicionalO intervalo do piscar cai de 500 ms para 80 ms conforme o objeto se aproxima

Exemplo com limite de 20 cm configurado no potenciômetro: acima de 20 cm o LED fica apagado; entre 10 e 20 cm ele pisca (acelerando); abaixo de 10 cm permanece aceso.

🔌 Circuito montado no Tinkercad

TRIG → D9 · ECHO → D10 — disparo de 10 µs e medição do tempo de eco com pulseIn().
Potenciômetro → A0 — extremos em 5 V e GND, cursor no analógico; mapeado para 5–50 cm.
LED → D7 — em série com resistor de 220 Ω até o GND.
Cálculo — distância (cm) = duração × 0,0343 ÷ 2.
🔗 Abrir circuito no Tinkercad

💻 Código do Arduino

/* =========================================================
   DESAFIO 2 - ESTACIONAMENTO INTELIGENTE
   HC-SR04 (distancia) + potenciometro (limite) -> LED
   Objeto distante          -> LED desligado
   Objeto se aproximando    -> LED piscando (cada vez mais rapido)
   Objeto na zona critica   -> LED ligado continuamente
   ========================================================= */

const int PINO_TRIG = 9;
const int PINO_ECHO = 10;
const int PINO_POT  = A0;
const int PINO_LED  = 7;

unsigned long ultimoPisca = 0;
bool estadoLed = false;

// Le a distancia em centimetros a partir do HC-SR04
float lerDistanciaCm() {
  digitalWrite(PINO_TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(PINO_TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(PINO_TRIG, LOW);

  unsigned long duracao = pulseIn(PINO_ECHO, HIGH, 30000UL);
  if (duracao == 0) return 400.0;          // nada detectado no alcance
  return duracao * 0.0343 / 2.0;           // velocidade do som -> cm
}

void setup() {
  pinMode(PINO_TRIG, OUTPUT);
  pinMode(PINO_ECHO, INPUT);
  pinMode(PINO_LED, OUTPUT);
  Serial.begin(9600);
  Serial.println("Sistema de Estacionamento Inteligente iniciado");
}

void loop() {
  float distancia = lerDistanciaCm();
  int   leituraPot = analogRead(PINO_POT);          // 0 .. 1023
  int   limite = map(leituraPot, 0, 1023, 5, 50);   // limite de seguranca em cm
  float critico = limite / 2.0;

  if (distancia > limite) {
    // Fora da zona monitorada
    digitalWrite(PINO_LED, LOW);
    estadoLed = false;
  } else if (distancia > critico) {
    // DESAFIO ADICIONAL: intervalo diminui conforme o objeto se aproxima
    int intervalo = map((int)distancia, (int)critico, limite, 80, 500);
    intervalo = constrain(intervalo, 80, 500);
    if (millis() - ultimoPisca >= (unsigned long)intervalo) {
      ultimoPisca = millis();
      estadoLed = !estadoLed;
      digitalWrite(PINO_LED, estadoLed ? HIGH : LOW);
    }
  } else {
    // Zona critica: alerta continuo
    digitalWrite(PINO_LED, HIGH);
    estadoLed = true;
  }

  Serial.print("Distancia=");  Serial.print(distancia, 1);
  Serial.print(" cm  Limite="); Serial.print(limite);
  Serial.print(" cm  LED=");    Serial.println(estadoLed ? "ON" : "OFF");

  delay(60);
}

Desafio 3

Ambiente Inteligente (Estufa)

🌱

Temperatura + Umidade → LEDs indicadores

Monitoramento contínuo da estufa com sinalização visual das condições e comunicação de dados pelo Monitor Serial.

🧩 Componentes obrigatórios

Arduino Uno R3 LED verde LED vermelho LED amarelo 3 × Resistor 220 Ω Sensor de temperatura e umidade DHT22 Protoboard e jumpers

📐 Regras de funcionamento

Condição adequadaT ≤ 30 °C e U ≥ 50 % → LED verde ligado
Temperatura elevadaT > 30 °C → LED vermelho ligado
Umidade inadequadaU < 50 % → LED amarelo ligado
Desafio adicionalT alta + U baixa → vermelho e amarelo piscam juntos, sinalizando alerta duplo

Valores de referência definidos para a cultura simulada: temperatura máxima de 30 °C e umidade relativa mínima de 50 %. A representação do alerta duplo usa piscar sincronizado, diferenciando-o das condições isoladas (LEDs fixos).

🔌 Circuito montado no Tinkercad

DHT22 DATA → D2 — leitura digital de temperatura e umidade a cada 2 s.
LED verde → D5 — indica condição adequada do ambiente.
LED vermelho → D6 — indica temperatura acima do limite.
LED amarelo → D7 — indica umidade abaixo do limite.
🔗 Abrir circuito no Tinkercad

💻 Código do Arduino

/* =========================================================
   DESAFIO 3 - AMBIENTE INTELIGENTE (ESTUFA)
   DHT22 (temperatura + umidade) -> LEDs indicadores
   Verde    -> condicao adequada
   Vermelho -> temperatura acima do limite
   Amarelo  -> umidade abaixo do limite
   Alerta duplo (T alta + U baixa) -> vermelho e amarelo piscando
   Comunicacao de dados via Monitor Serial (9600 baud)
   ========================================================= */

#include <DHT.h>

#define PINO_DHT  2
#define TIPO_DHT  DHT22

const int LED_VERDE    = 5;
const int LED_VERMELHO = 6;
const int LED_AMARELO  = 7;

const float TEMP_MAX = 30.0;  // limite superior de temperatura (C)
const float UMID_MIN = 50.0;  // limite inferior de umidade (%)

DHT dht(PINO_DHT, TIPO_DHT);

unsigned long ultimoPisca = 0;
bool piscaEstado = false;

void setup() {
  pinMode(LED_VERDE, OUTPUT);
  pinMode(LED_VERMELHO, OUTPUT);
  pinMode(LED_AMARELO, OUTPUT);
  dht.begin();
  Serial.begin(9600);
  Serial.println("Sistema de Ambiente Inteligente iniciado");
  Serial.println("Temp(C);Umid(%);Estado");
}

void loop() {
  float temperatura = dht.readTemperature();
  float umidade     = dht.readHumidity();

  if (isnan(temperatura) || isnan(umidade)) {
    Serial.println("Falha na leitura do DHT22");
    delay(2000);
    return;
  }

  bool tempAlta  = temperatura > TEMP_MAX;
  bool umidBaixa = umidade < UMID_MIN;

  if (tempAlta && umidBaixa) {
    // DESAFIO ADICIONAL: duas condicoes simultaneas -> piscar sincronizado
    if (millis() - ultimoPisca >= 300) {
      ultimoPisca = millis();
      piscaEstado = !piscaEstado;
    }
    digitalWrite(LED_VERDE, LOW);
    digitalWrite(LED_VERMELHO, piscaEstado ? HIGH : LOW);
    digitalWrite(LED_AMARELO,  piscaEstado ? HIGH : LOW);
  } else {
    digitalWrite(LED_VERMELHO, tempAlta  ? HIGH : LOW);
    digitalWrite(LED_AMARELO,  umidBaixa ? HIGH : LOW);
    digitalWrite(LED_VERDE, (!tempAlta && !umidBaixa) ? HIGH : LOW);
  }

  // Comunicacao de dados: leitura + estado do sistema
  Serial.print(temperatura, 1); Serial.print(";");
  Serial.print(umidade, 1);     Serial.print(";");
  if (tempAlta && umidBaixa)  Serial.println("ALERTA DUPLO: TEMP ALTA + UMIDADE BAIXA");
  else if (tempAlta)          Serial.println("TEMPERATURA ALTA");
  else if (umidBaixa)         Serial.println("UMIDADE BAIXA");
  else                        Serial.println("CONDICAO ADEQUADA");

  delay(2000);   // DHT22 suporta 1 leitura a cada 2 segundos
}

Considerações finais

Integração, rastreabilidade e validação

Os três protótipos compartilham a mesma arquitetura de sensoriamento e controle: leitura periódica das entradas, aplicação de regras de decisão baseadas em limites configuráveis e acionamento das saídas. O registro das leituras e do estado do sistema no Monitor Serial garante a rastreabilidade exigida no ambiente industrial, permitindo comparar o comportamento esperado com o observado a cada teste — exatamente o que os quadros de teste acima documentam.
